# UI Module (Dashboard Web)

Thư mục giữ chỗ cho giao diện người dùng (Phase 6):
- Frontend xây dựng bằng React + Tailwind CSS (hoặc Next.js / Vite).
- Hỗ trợ 2 chế độ hiển thị:
  1. **Chế độ Chuyên gia**: Biểu đồ phân tích kỹ thuật, đối chiếu mô hình, phân rã mùa vụ, xuất CSV.
  2. **Chế độ Đơn giản cho Nông dân (Section 5.4, NFR-11, NFR-12)**: Cỡ chữ lớn (>=18px), nút bấm tối thiểu 48x48px, độ tương phản cao WCAG AA, hiển thị rõ ràng xu hướng tăng/giảm bằng số và mũi tên, ngôn ngữ mộc mạc dễ hiểu.
